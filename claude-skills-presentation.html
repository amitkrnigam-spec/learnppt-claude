What Are Skills?

Skills are curated sets of best practices and instructions that guide Claude to produce high-quality, professional outputs. Think of them as expert knowledge packs that Claude reads before starting any task.

🧠

Domain Knowledge

Each skill contains tried-and-tested techniques refined through extensive trial and error with LLMs.

⚡

Auto-Activated

Claude automatically reads the right skill file before working, so you get great results without extra prompting.

How Skills Work

1

You Make a Request

Ask Claude to create a document, presentation, spreadsheet, or any supported output.

2

Claude Reads the Skill

Before writing any code or content, Claude reads the relevant SKILL.md file to load best practices.

3

Professional Output

The skill guides Claude through formatting, structure, and quality checks to deliver polished results.
